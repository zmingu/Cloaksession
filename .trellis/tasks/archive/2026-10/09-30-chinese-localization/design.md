# 中文化技术设计

## 状态与决策

范围和默认策略已由用户确认：完整应用界面、简体中文默认、英文可切换。本文待最终审阅；不授权实现。

## 架构

采用本地打包的类型安全中英字典与 React Context，不引入远程语言包或整套国际化依赖。当前只有两种语言，需求可由字典、具名插值和 Intl 满足；避免增加不必要依赖。若后续出现多语言 ICU/复杂复数需求，可在保持键命名和调用边界的前提下替换内部实现。

建议新增 `ui/src/i18n/`（相对 `crates/tauri-app/`），包含纯翻译函数、en/zh-CN 字典、类型、Provider/hook。采用按领域命名的稳定语义键，不拿英文整句当 key。英文基准键声明，中文满足同一键集合；参数用具名占位符并验证集合一致。所有用户插值作为文本节点，不使用 HTML 注入。数量句式明确提供必要变体，不拼接词序片段。

## 语言设置契约

- `AppSettings.language` 的 wire 值仅为 `zh-CN` 或 `en`，与 Profile.locale 无关；不存在 system 模式。
- 规范化集中在模型/设置所有者：AppSettings 默认 zh-CN；RawSettings 对语言字段宽容读取（可采用单字段 serde_json::Value 再解析），缺失/null/未知字符串/错误类型仅让语言回退，不能因新增字段的异常清空原先有效设置。
- IPC 更新接受已知值，非法显式更新返回错误；旧客户端不传 language 继续保留原值。沿用现有非 null 顶层合并，不改变 null/嵌套配置语义。
- 同步 Rust 模型、RawSettings、TS AppSettings、IPC fixtures。注意 AppSettings 新字段会影响 Rust struct literal 和测试工厂，实施时使用搜索盘点所有构造点。
- 存储沿用 SettingsStore。它不是原子写入机制，本任务不声称提供新的磁盘原子性；失败时不刷新缓存、不更新成功状态。

## 首屏与切换数据流

1. 入口在渲染完整应用前读取 settings，通过轻量启动占位避免已保存英文用户先看到整屏中文。初始 HTML lang 可为 zh-CN，设置加载后同步实际 document.lang。
2. 设置加载失败可进入中文回退界面并提供操作说明，不永久卡在等待状态；渲染错误边界使用不依赖 Provider 的纯翻译 fallback。
3. 设置页通过现有 IPC 保存 language，等待服务端返回成功再更新全局语言。期间禁用重复语言提交；不重建 App、不卸载表单，保留未保存输入和当前导航。
4. 时间/地区格式化显式接受应用语言，使用 Intl。通知与应用自行生成的活动说明保存语义键和参数或在渲染时映射稳定事件类型，避免已打开组件缓存旧语言。外部原始诊断不改写。
5. Provider 是界面语言状态唯一入口；不写 Profile、navigator 注入、浏览器 --lang、SDK locale 或代理调和流程。

## 文案覆盖边界

- 覆盖调研清单中所有应用组件及运行时错误边界；检查 title/aria-label/placeholder/空状态/确认按钮/工具提示。
- Profile 的国家/语言显示名称可跟随 UI；选项实际值保持不变。品牌、JSON keys、命令、MCP 工具名称及示例协议保持原样。
- 第三方 UI 控件（如 emoji picker）优先使用其已支持的本地化入口或本地数据，避免修改 vendor。开发前确认本地已安装版本 API；若无法覆盖，不能静默视作完成，应登记并回到规划评估。
- 活动面板翻译固定操作标签与状态，不翻译外部任意文本。扩展第三方标题/说明与发布说明保留原文。
- 统一术语：Profile 显示为“浏览器配置”，Fingerprint 为“浏览器指纹”，Locale 为“区域语言”；首次出现的技术术语可带英文辅助，不改变数据字段。

## 后端及原生提示

不修改共享 Rust Error 的 Display，不破坏 MCP/日志消费者。UI 捕获错误时使用操作级翻译 + 原始详情，禁止基于英文子串映射。

应用自定义原生文件过滤标签、更新提示文本从持久化应用语言选择 Rust 侧小型静态字典（仅原生提示所需键），不让前端传任意待执行/显示脚本。调用时读取设置快照，释放锁后再打开阻塞弹窗。跨前后端核心默认行为一致并测试。OS 的选择器按钮和装饰由系统语言控制。

## 兼容与风险

- 老设置文件自然加载为中文；这包含原英文用户，是用户明确选择的行为。
- 不修改现有 autoUpdate 默认差异、事件 payload 已知问题、更新器历史命名或端口等无关问题。
- 中文字形使用可靠系统字体 fallback；不以访问外部字体 CDN 为中文可读性的前提。
- 不刷新已打开的 OS 模态窗口，后续新弹窗使用已保存语言；应用 React 弹窗随 Context 更新。
- 词条迁移漏项、英语长度回归和第三方控件为主要 UI 风险；用文案清单、两语言测试和截图检查管理。

## 回滚

以功能批次隔离改动：设置模型、翻译基础、组件迁移、原生提示与验证。回退代码时不修改 profiles.db，不删除用户设置；新增 language 字段不要求数据库迁移。回滚前确认当时是否有用户更改，禁止硬重置或覆盖共享设置文件。
