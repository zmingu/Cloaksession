# 应用中文化

## Goal

让中文用户完整使用 Cloaksession 管理应用，同时保留英文切换能力。用户于 2026-09-30 批准调研规划，随后选择范围 A 与默认语言策略 1；实施仍需最终总结后的单独批准。

## Background

- Tauri 2 + React 19 当前没有统一国际化机制；文案分散于设置、表单、引导等界面。证据：`crates/tauri-app/ui/package.json:13-32`、`crates/tauri-app/ui/src/components/screens/Settings.tsx:100-389`。
- 已有 settings.json 持久化和 IPC patch 合并（`crates/tauri-app/src/commands/settings.rs:23-48`）。
- 后端通过英文错误字符串提供诊断，没有统一可用错误码（`crates/multizen-core/src/error.rs:4-31`）。
- 调研清单、定位及验证入口：`research/localization-audit.md`。

## Requirements

- R1：基于代码调研建立可维护的中文化方案，列明范围、风险和验证方式。
- R2：第一阶段覆盖应用自有完整界面：导航、配置列表、新建/编辑、指纹、代理、扩展、设置、MCP、活动、命令面板、引导、通知、确认框、应用自定义原生提示，以及辅助功能名称、占位符、时间和地区显示。支持简体中文和英文，不以仅翻译导航作为完成标准。
- R3：界面语言不改变协议值、浏览器参数或用户数据。Profile.locale/Accept-Language 实际影响浏览器启动（`crates/browser-launcher/src/args.rs:146-147`），必须与管理应用语言隔离。
- R4：最终规划总结获用户单独批准前不修改业务代码、不启动实现。
- R5：首次安装及旧配置未保存语言时默认简体中文，不跟随系统；设置中可切换 English/简体中文，保存成功后无需重启，后续启动保留选择。保存失败不假装成功，不改动其他设置。
- R6：中文模式下应用提供本地化的操作级错误说明，并保留原始技术详情；不通过英文子串猜测错误类别。未知底层错误、外部内容可保留原文。
- R7：异常语言值回退简体中文且不清空其他有效设置；已选语言缺少词条时回退英文，不显示 undefined 或空白。中文和英文词条完整性纳入自动检查。

## Acceptance Criteria

- AC1（R1/R4）：研究、设计、执行计划及实际 spec/research 上下文均已落盘；实施前获得用户审阅批准。
- AC2（R2/R5）：新配置与旧版无语言字段配置打开即为中文；手动改英文后所有当前应用自有界面随之更新，重启仍为英文。
- AC3（R2）：完整核心流程中无未登记的应用自有英文残留；品牌、缩写、协议值、用户数据、外部内容与技术详情属于明确例外。主要弹窗、表单在现有桌面/窄屏视口下无遮挡或不可操作的截断。
- AC4（R3）：切换语言前后 Profile 指纹、代理、用户名称/备注/标签及 Chromix 原始选项不变；传给浏览器/IPC 的业务枚举值不变。
- AC5（R5/R7）：设置缺字段、非法语言字符串、语言字段类型异常、保存失败、缓存读取与重新打开均有测试；失败显示清晰提示且内存选择不冒充已保存。
- AC6（R2/R6）：时间与地区显示使用应用语言；document.lang 更新；错误包含中文操作说明及可读取的原始诊断。系统控制的按钮不要求随应用语言变化。
- AC7（R2/R7）：中英字典键与插值参数检查、UI 构建、settings-store 测试和相关 UI 回归通过；原生效果单独实测，未执行项目明确标注，不能用 mock IPC 测试代替原生验证。

- 操作系统按钮、窗口装饰、第三方服务返回文本、用户内容和完整后端错误码协议重构。
- 翻译品牌名 Cloaksession、技术标识、MCP 工具协议/JSON 示例键、日志原始诊断、上游发布说明或 SDK 配置键。
- 无关功能修复、浏览器下载、安装包发布和 vendored Chromix 源码改造。
